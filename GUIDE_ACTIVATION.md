# Guide d’activation (à mettre en place)

Ce document sert de base pour vos procédures d’activation. Adaptez les étapes selon les produits que vous vendez (Windows, Office, Antivirus, etc.).

## Prérequis

- Une licence achetée (clé) visible dans **Mon espace client**.
- Une connexion Internet stable.
- Les droits administrateur sur l’ordinateur (si nécessaire).

## Où trouver ma clé ?

1. Connectez-vous.
2. Ouvrez **Mon espace client**.
3. Dans **Mes licences**, affichez puis copiez votre clé.

## Activation Windows (exemple)

1. Ouvrez **Paramètres** → **Système** → **Activation**.
2. Cliquez sur **Modifier la clé de produit**.
3. Collez la clé, validez.
4. Redémarrez l’ordinateur si demandé.

### Dépannage Windows

- Vérifiez que l’édition Windows installée correspond à la licence.
- Désactivez temporairement VPN/Proxy.
- Si l’activation échoue : relancez et réessayez plus tard.

## Activation Microsoft Office (exemple)

1. Installez Office (si ce n’est pas déjà fait).
2. Ouvrez Word/Excel → **Compte**.
3. Cliquez sur **Activer** / **Se connecter** selon la méthode fournie.
4. Saisissez la clé si demandé.

### Dépannage Office

- Vérifiez la version (Office 2019/2021/365…).
- Désinstallez les anciennes versions si conflit.
- Lancez Office en administrateur si nécessaire.

## Support

Si vous avez un problème d’activation, utilisez le bouton **Contacter le support** dans **Mon espace client** (WhatsApp).
